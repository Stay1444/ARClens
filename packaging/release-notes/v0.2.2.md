## What's new in 0.2.2

- **Project progress, read from the game.** With screen reading on, open
  a project's page (PROJECTS → Trophy Display): ARClens takes its current
  phase and what you've delivered to it so far. What's delivered no
  longer counts as needed, in KEEP advice, the Planner and item pages,
  and the Progress page shows it ("6 items delivered to it so far").
  Looking at a later, locked phase never moves your progress forward.
- **Only the projects the game has.** Old expeditions (seasons 1-4) and
  Phantom Targets are gone from Progress and the Planner, and their items
  no longer count as reasons to keep. Season 5's expedition stays for
  when expeditions come back from their rework.

New in game and not tried there yet: a project page with something
delivered. Reports (with a screenshot) are very welcome.

## Downloads

| File | For |
|---|---|
| `ARClens-0.2.2-x86_64.AppImage` | Linux, glibc 2.39+ (Fedora 40+, Ubuntu 24.04+) with PipeWire. `chmod +x` and run. |
| `ARClens-0.2.2-x86_64.flatpak` | Linux. `flatpak install --user ARClens-0.2.2-x86_64.flatpak`, then `flatpak run io.github.Stay1444.ARClens`. |
| `ARClens-0.2.2-windows-x86_64.zip` | Windows 10/11. Unzip and run `arclens.exe` (keep `arclens-overlay.exe` next to it). |

**Upgrading the Flatpak:** quit ARClens first (`flatpak kill
io.github.Stay1444.ARClens`), and install into the same place as before.

Same protocol between app and overlay as 0.2.0 (v21). Game data comes
from [RaidTheory/arcraiders-data](https://github.com/RaidTheory/arcraiders-data)
and [MetaForge](https://metaforge.app/arc-raiders). Fan-made, not
affiliated with Embark Studios.
