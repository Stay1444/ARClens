## What's new in 0.1.4

- **Stash scan progress.** A bar above the stash says to scroll down,
  counts the slots seen so far ("28 / 75") and turns green when the whole
  stash has been read and the scan is saved.
- **Filter tabs.** Only the first tab (all items) feeds the scan, so a
  filtered view can no longer end up in the wrong place in it. Other tabs
  still get KEEP / SELL / RECYCLE / LEARN tags; the bar asks for the
  first tab, and the scan carries on when you go back to it.
- **Fixes.**
  - Tags came back only after restarting ARClens: closing the stash once
    stopped the scan for good.
  - On a filtered tab, the stash's slot total is no longer read from the
    tab's own count.

## Downloads

| File | For |
|---|---|
| `ARClens-0.1.4-x86_64.AppImage` | Linux, glibc 2.39+ (Fedora 40+, Ubuntu 24.04+) with PipeWire. `chmod +x` and run. |
| `ARClens-0.1.4-x86_64.flatpak` | Linux. `flatpak install --user ARClens-0.1.4-x86_64.flatpak`, then `flatpak run io.github.Stay1444.ARClens`. |
| `ARClens-0.1.4-windows-x86_64.zip` | Windows 10/11. Unzip and run `arclens.exe` (keep `arclens-overlay.exe` next to it). |

**Upgrading the Flatpak:** quit ARClens first (`flatpak kill
io.github.Stay1444.ARClens`), and install into the same place as before.

The stash scan has only been tested on recordings and screenshots at
2560×1440 and 2000×1125 so far: reports of wrong tags (with a screenshot
showing the item's tooltip) are very welcome.

Update both the app and the overlay together: the protocol between them
changed (v18). Game data comes from
[RaidTheory/arcraiders-data](https://github.com/RaidTheory/arcraiders-data)
and [MetaForge](https://metaforge.app/arc-raiders). Fan-made, not
affiliated with Embark Studios.
