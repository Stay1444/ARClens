## What's new in 0.2.1

- **Plan for many goals at once.** The Planner no longer takes one goal at
  a time: pick any benches (or "All benches"), projects and expeditions,
  and items to craft, in no order, each to its next level / phase or all
  the way. What they take is added up, your stash is counted once across
  all of them, and the list shows what to craft from parts, what's
  missing, and which spare items to recycle. Your goals are saved.
- Projects with the same name in the data are numbered ("Phantom Targets
  1", "2").
- The loading-screen card says how many goals you have and what they
  still miss.
- Tests pass Clippy 1.99's new checks.

## Downloads

| File | For |
|---|---|
| `ARClens-0.2.1-x86_64.AppImage` | Linux, glibc 2.39+ (Fedora 40+, Ubuntu 24.04+) with PipeWire. `chmod +x` and run. |
| `ARClens-0.2.1-x86_64.flatpak` | Linux. `flatpak install --user ARClens-0.2.1-x86_64.flatpak`, then `flatpak run io.github.Stay1444.ARClens`. |
| `ARClens-0.2.1-windows-x86_64.zip` | Windows 10/11. Unzip and run `arclens.exe` (keep `arclens-overlay.exe` next to it). |

**Upgrading the Flatpak:** quit ARClens first (`flatpak kill
io.github.Stay1444.ARClens`), and install into the same place as before.

Same protocol between app and overlay as 0.2.0 (v21). Game data comes
from [RaidTheory/arcraiders-data](https://github.com/RaidTheory/arcraiders-data)
and [MetaForge](https://metaforge.app/arc-raiders). Fan-made, not
affiliated with Embark Studios.
