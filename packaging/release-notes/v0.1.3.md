## What's new in 0.1.3

- **Stash scan.** Open your stash with game capture on and scroll through
  it once: ARClens reads every slot from the screen, recognises the item
  by its icon (with its tier numeral and stack size) and tags each slot
  in the overlay with KEEP, SELL, RECYCLE or LEARN.
  - A **"?"** means the item was matched from its icon alone. Hover it
    once: the tooltip settles it, and ARClens remembers that slot's
    picture from then on.
  - Tags hide while the grid scrolls and come back when it stops.
  - The first time, ARClens downloads every item's image (about 590
    small files, once) to compare icons against.
- **Progress → Stash.** Your latest scan, everything your remaining
  workshop upgrades, quests and projects still need against what you
  have, and earlier scans with what changed.
- **Fixes.**
  - Short tooltips (ammo) are read again.
  - Looting Mk. 2's name no longer reads as "0".
  - A browser's address bar is no longer taken for the in-game map tab
    (a YouTube page opened the map panel).

## Downloads

| File | For |
|---|---|
| `ARClens-0.1.3-x86_64.AppImage` | Linux, glibc 2.39+ (Fedora 40+, Ubuntu 24.04+) with PipeWire. `chmod +x` and run. |
| `ARClens-0.1.3-x86_64.flatpak` | Linux. `flatpak install --user ARClens-0.1.3-x86_64.flatpak`, then `flatpak run io.github.Stay1444.ARClens`. |
| `ARClens-0.1.3-windows-x86_64.zip` | Windows 10/11. Unzip and run `arclens.exe` (keep `arclens-overlay.exe` next to it). |

**Upgrading the Flatpak:** quit ARClens first (`flatpak kill
io.github.Stay1444.ARClens`), and install into the same place as before.

The stash scan is new and has only been tested on recordings at
2560×1440 so far: reports of wrong tags (with a screenshot showing the
item's tooltip) are very welcome.

Update both the app and the overlay together: the protocol between them
changed (v17). Game data comes from
[RaidTheory/arcraiders-data](https://github.com/RaidTheory/arcraiders-data)
and [MetaForge](https://metaforge.app/arc-raiders). Fan-made, not
affiliated with Embark Studios.
