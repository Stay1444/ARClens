## What's new in 0.1.2

- **Pick search results with the arrow keys.** ↑/↓ move a highlight
  through the quick-search results (wrapping at the ends); Enter opens
  the highlighted one.
- **Esc closes the search.** Esc still closes the newest item window;
  with none open, it closes the search box and leaves interactive mode.
- **The Flatpak file name carries the version**
  (`ARClens-0.1.2-x86_64.flatpak`), so an old download is easy to tell
  from a new one.

## Downloads

| File | For |
|---|---|
| `ARClens-0.1.2-x86_64.AppImage` | Linux, glibc 2.39+ (Fedora 40+, Ubuntu 24.04+) with PipeWire. `chmod +x` and run. |
| `ARClens-0.1.2-x86_64.flatpak` | Linux. `flatpak install --user ARClens-0.1.2-x86_64.flatpak`, then `flatpak run io.github.Stay1444.ARClens`. |
| `ARClens-0.1.2-windows-x86_64.zip` | Windows 10/11. Unzip and run `arclens.exe` (keep `arclens-overlay.exe` next to it). |

**Upgrading the Flatpak:** quit ARClens first (`flatpak kill
io.github.Stay1444.ARClens`), and install into the same place as before
(`--user` or system-wide). `flatpak list --app --columns=application,version,installation`
shows what's installed; the bottom of Settings shows the running version.

Update both the app and the overlay together: the protocol between them
changed (v16). Game data comes from
[RaidTheory/arcraiders-data](https://github.com/RaidTheory/arcraiders-data)
and [MetaForge](https://metaforge.app/arc-raiders). Fan-made, not
affiliated with Embark Studios.
