First public release of ARClens, a companion app and in-game overlay for
ARC Raiders. Linux first (KDE Plasma 6 on Wayland), Windows too.

> **Early development.** Most features work, and some are verified on a
> real desktop; the packages themselves haven't been fully checked on
> every setup yet. Reports are welcome in the issues.

## What it does

- **Item advice on hover**: a card beside the game's tooltip says KEEP,
  SELL, RECYCLE or LEARN, with values, recycle outputs and what still
  needs the item.
- **Map markers on the in-game map**: community-mapped loot spots, ARC,
  exits and quest spots, following the map as you pan and zoom, with
  presets per map condition and marker tooltips.
- **Companion app**: item search, the map with every marker (Stella
  Montis per floor), map-condition timers for your region, and progress
  (workshop, quests, projects, blueprints), mostly filled in from the
  game's own screens.
- **Languages**: English and Spanish (Spain).
- **Stays out of the game**: reads the screen through the OS's screen
  capture, like a recorder. No memory reading, no injection, no hooks.
  See "Is this ethical?" in the README.

## Downloads

| File | For |
|---|---|
| `ARClens-0.1.0-x86_64.AppImage` | Linux, glibc 2.39+ (Fedora 40+, Ubuntu 24.04+) with PipeWire. `chmod +x` and run. |
| `ARClens-x86_64.flatpak` | Linux. `flatpak install --user ARClens-x86_64.flatpak`, then `flatpak run io.github.Stay1444.ARClens`. |
| `ARClens-0.1.0-windows-x86_64.zip` | Windows 10/11. Unzip and run `arclens.exe` (keep `arclens-overlay.exe` next to it). |

Game data comes from [RaidTheory/arcraiders-data](https://github.com/RaidTheory/arcraiders-data)
and [MetaForge](https://metaforge.app/arc-raiders); see the README's
"Data and attribution". Fan-made, not affiliated with Embark Studios.
