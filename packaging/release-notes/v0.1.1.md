## What's new in 0.1.1

- **Item windows from the quick search.** Ctrl+Shift+I, type, Enter: the
  item opens in its own window next to the search box with everything
  the game data has — verdict, values, weight and value per kg, stats,
  recycle and salvage outputs, recipe and crafting bench, what it crafts,
  upgrade tiers and costs, repair cost, which traders sell it (price,
  limit, level), mod slots, where it drops, blueprint state, and your
  progress on what still needs it. Open up to four side by side; close
  each with ✕, the newest with Esc, or all at once. The search box clears
  after each pick and keeps the keyboard. This replaces the card that
  used to pin itself in the top-right corner with no way to close it.
- **Map tooltips follow the game's own cursor.** The game hides the
  system pointer and draws its own, so hovering markers on the in-game
  map didn't work; ARClens now finds the game's arrow on screen.
- **Markers fade near the cursor**, so the map under it stays readable.
- **Controls page** on the main-menu card: the hotkeys at a glance.
- **Licence:** ARClens is now GPL-3.0-or-later; every package ships the
  licence text.
- Settings shows the version; Spanish workshop station titles (`NIVEL`)
  are read too.
